Português

Jogo de cartas desenvolvido na Unity, inspirado no clássico Super Trunfo.

Desenvolvido utilizando Unity e C#.

Como rodar
Clone o repositório
Acesse a pasta Build
Execute o arquivo .exe

Principais funcionalidades
-60 cartas únicas
-IA adversária capaz de escolher atributos de forma estratégica
-Modos de jogo: partidas curtas ou longas
-Gameplay simples e acessível
-Funcionamento da IA

A IA utiliza uma abordagem baseada em média de atributos:

-Durante a inicialização, é calculado o valor médio de cada atributo
-Em cada turno, a IA verifica quais atributos da carta atual estão acima da média
-Um desses atributos é selecionado aleatoriamente
-Caso nenhum atributo esteja acima da média, a IA escolhe um atributo aleatório

English

Card game developed in Unity, inspired by the classic Top Trumps.
Built using Unity and C#.

How to run
-Clone the repository
-Open the Build folder
-Run the .exe file

Main features
-60 unique cards
-AI opponent capable of selecting attributes strategically
-Game modes: short or long matches
-Simple and accessible gameplay

AI Behavior

The AI uses an attribute-average-based approach:
-During initialization, the average value of each attribute is calculated
-On each turn, the AI checks which attributes of the current card are above average
-One of these attributes is randomly selected
-If no attribute is above average, a random attribute is chosen
